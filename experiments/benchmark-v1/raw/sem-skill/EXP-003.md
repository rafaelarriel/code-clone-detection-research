## Candidatos fracos excluídos como falsos positivos

Não classifiquei os pares abaixo como clones acionáveis, apesar de um detector puramente sintático poder sinalizá-los:

- discounts.py::discount_ten_percent (4–5), discount_fifteen_percent (8–9) e add_sales_tax (12–13): compartilham a forma return price * constante, mas representam regras financeiras diferentes. Sob uma definição muito permissiva, seriam Tipo 2 por substituição de literal; tecnicamente, seria um falso positivo para refatoração.
- Predicados unitários de permissions.py (4–25), como is_adult, is_minor, is_positive, is_nonnegative, is_even e is_odd: têm formato similar, mas cada operador e limiar define uma regra distinta. O fragmento é pequeno demais e semanticamente específico para justificar abstração.
- analytics.py::average (35–36) reutiliza conceitualmente uma soma, mas não contém uma duplicação de implementação suficientemente relevante: usa sum(numbers) / len(numbers) diretamente.

A principal área de refatoração com melhor custo-benefício é billing.py: centralizar o subtotal elimina simultaneamente clones dos Tipos 1, 2, 3 e 4.
